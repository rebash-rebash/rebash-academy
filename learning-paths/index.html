    Learning Paths¶

    Choose a structured path based on your career goals. Each path builds on the previous sections and ends with production-ready projects.

    Primary Path – DevOps Engineer¶

    The recommended path for engineers building a full-stack DevOps skill set:

    flowchart TD
    A[Linux Engineer] --> B[Networking]
    B --> C[Git]
    C --> D[Docker]
    D --> E[Kubernetes]
    E --> F[Terraform]
    F --> G[Cloud]
    G --> H["CI/CD"]
    H --> I[Monitoring]
    I --> J[Security]
    J --> K[Production Projects]
    Step Section Description
    1 Linux Command line, system admin, shell scripting
    2 Networking TCP/IP, DNS, load balancing, troubleshooting
    3 Git Version control and collaboration workflows
    4 Docker Containerization fundamentals
    5 Kubernetes Container orchestration at scale
    6 Terraform Infrastructure as Code
    7 Cloud AWS, Azure, or GCP specialization
    8 GitLab CI/CD Pipeline automation and GitOps
    9 Monitoring Observability and alerting
    10 Security Hardening and compliance
    11 Projects Portfolio-ready production projects
