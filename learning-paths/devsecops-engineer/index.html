    DevSecOps Engineer¶

    Duration: 14–20 weeks · Difficulty: advanced · Badge: Security

    Shift-left security across containers, Kubernetes, pipelines, and cloud.

    Complete roadmap¶

    1. Linux
    2. Docker
    3. Kubernetes
    4. Git
    5. GitLab CI/CD
    6. DevSecOps
    7. Security
    8. AWS
    9. Terraform

    Target audience¶

    Engineers who want the DevSecOps Engineer skill profile and job outcomes below.

    Job roles¶

    • DevSecOps Engineer
    • Security Engineer (Cloud)
    • AppSec Engineer

    Expected salary ranges¶

    Mid to senior security engineering roles — treat as directional guidance only.

    Prerequisites¶

    • Comfort with a laptop and a terminal
    • Complete earlier phases before later ones when marked ready
    • Prefer the Getting Started overview if you are new to the academy

    Phases¶

    Foundations¶

    • Linux — ready · 25 tutorials
    • Docker — ready · 20 tutorials
    • Kubernetes — ready · 20 tutorials
    • Git — ready · 20 tutorials
    • GitLab CI/CD — ready · 20 tutorials

    Cloud¶

    • AWS — ready · 20 tutorials
    • Terraform — ready · 20 tutorials

    Skills gained¶

    • Ordered mastery of the technologies on this path
    • Hands-on labs and production-oriented habits

    Projects¶

    See the Projects catalog and Capstones. Map picks to this path’s technologies.

    Capstone¶

    Choose a capstone that exercises the final phases of this path (for example Status API for DevOps / Kubernetes, or the Python automation framework for AI for DevOps).

    Interview roadmap¶

    1. Finish ready technology tracks on this path
    2. Use Interview Guides per technology
    3. Rehearse troubleshooting stories from labs

    Certification roadmap¶

    CKS, AWS Security Specialty

    Related learning paths¶

    • Beginner
    • Linux Administrator
    • Cloud Engineer
    • DevOps Engineer

    Estimated duration¶

    14–20 weeks of focused study (tutorials + labs). Stretch if you are new to Linux or cloud.
