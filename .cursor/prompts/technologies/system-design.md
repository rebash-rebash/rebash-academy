# Technology Definition

## Course

System Design for Software Engineers

---

## Description

A production-focused System Design course for software engineers and aspiring engineers.

Teach how to turn vague product ideas into clear requirements, honest trade-offs, labelled architectures, and runnable Python implementations — with heavy use of architecture diagrams and realtime-ready patterns in later modules.

---

## Target Roles

- Software Engineer
- Backend Engineer
- Full-stack Engineer
- Aspiring Software Engineer
- DevOps / Platform Engineer (service design)
- Technical Lead

---

## Difficulty

Intermediate → Advanced

---

## Estimated Duration

12–14 weeks

## Lab language

Python (default for sample services and labs)

- HTTP basics

- Git

1. How to design a system
2. Quality attributes and trade-offs
3. Application architecture styles
4. Client → edge → service path

5. Data storage *(ready)*
6. Caching *(ready)*

9. Observability and resilience *(ready)*

### Part C — Classic systems

10. URL shortener *(ready)*
11. News feed / timeline *(ready)*
12. File / media upload *(ready)*
13. Search / autocomplete *(ready)*

### Part D — Realtime

14. Realtime chat *(ready)*
15. Live notifications and presence *(ready)*
16. Collaborative / streaming patterns *(ready)*
17. Capstone — realtime collaboration board *(ready)*
