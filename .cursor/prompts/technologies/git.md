# Technology Definition

## Course

Git & GitHub for Cloud & DevOps Engineers

---

## Description

A practical Git and GitHub course designed specifically for Cloud, DevOps, Platform Engineering and Site Reliability Engineering.

This course focuses on real-world Git workflows, collaborative development, Infrastructure as Code (IaC), GitOps, CI/CD and repository management rather than basic version control alone.

Learners should finish the course capable of managing enterprise Git repositories, collaborating effectively and implementing GitOps workflows.

---
