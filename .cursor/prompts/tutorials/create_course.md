# Create Course Prompt

Use this prompt when creating or improving a REBASH Academy course.

## Course goal

Design a complete learning journey from student to professional. The course should start with fundamentals, build practical skill through labs, and end with production judgement, troubleshooting ability, and portfolio-ready work.

## Required process

1. Search existing `docs/` courses and `.cursor/prompts/technologies/`.
2. Reuse established repository structure and naming.
3. Define modules with clear progression.
4. Map tutorials, labs, quizzes, interview preparation, projects, and capstone work.
5. Avoid duplicate topics unless the new course has a distinct audience or depth.

## Progression model

Each course should include:

- **Foundation:** core vocabulary, mental models, installation, and safe local practice.
- **Operations:** daily workflows, command usage, configuration, automation, and debugging.
- **Production:** security, reliability, observability, performance, cost, governance, and failure handling.
- **Professional proof:** labs, projects, capstone, interview questions, and portfolio deliverables.

## Module design

Each module must answer:

- What can the learner do after this module?
- What practical scenario does it prepare them for?
- What failure mode or production risk should they recognise?
- How does it connect to the next module?

## Quality bar

- No module should be only theory.
- No advanced module should skip operational evidence.
- No beginner module should be patronising or vague.
- Every course should support self-study, interview preparation, and real work readiness.
