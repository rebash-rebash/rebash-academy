# Interview Preparation

Each tutorial ends with five topic-specific interview questions. Focus areas for this track:

- Controller versus agent architecture
- Why not build on the built-in node
- Declarative versus Scripted Pipeline
- Multibranch and pull request isolation
- Shared library trust model
- Credentials and Cross-Site Request Forgery (CSRF)
- Jenkins Configuration as Code (JCasC) and upgrade strategy

Browse the [Academy interview catalog](../../interview/) and start with [Introduction to Jenkins and CI/CD](../introduction-to-jenkins-and-ci-cd.md).
