# Certifications

REBASH Academy tutorials support practical preparation for common industry exams.
The focus stays on engineering skill, not exam memorisation — the mapping below shows
which tracks cover each certification's ground.

| Certification | Vendor | Supporting tracks |
|---------------|--------|-------------------|
| RHCSA / RHCE | Red Hat | [Linux](../linux/index.md), [Shell Scripting](../shell/index.md) |
| CKA / CKAD / CKS | CNCF | [Kubernetes](../kubernetes/index.md), [Docker](../docker/index.md), [Helm](../helm/index.md) |
| Terraform Associate | HashiCorp | [Terraform](../terraform/index.md) |
| Solutions Architect Associate | AWS | [AWS](../aws/index.md), [Networking](../networking/index.md) |
| AZ-104 / AZ-305 | Microsoft | [Azure](../azure/index.md) |
| Associate Cloud Engineer, Professional Cloud Architect / DevOps Engineer | Google Cloud | [Google Cloud](../gcp/index.md) |

## How to prepare

1. Finish the supporting tutorial track and its labs.
2. Use the track's [cheat sheet](../cheatsheets/index.md) for command recall.
3. Take the matching [quiz](../quizzes/index.md) — the 70% pass mark mirrors exam pressure.
4. Build at least one [project](../projects/index.md) so the knowledge sticks.

Dedicated per-certification study guides will be published here as they are ready.
