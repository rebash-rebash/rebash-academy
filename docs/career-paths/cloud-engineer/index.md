# Cloud Engineer

Build and operate cloud infrastructure on AWS (Azure and GCP next).

| | |
|--|--|
| **Duration** | 12–16 weeks |
| **Difficulty** | intermediate |
| **Badge** | Cloud |

## Target audience

Engineers who want the **Cloud Engineer** skill profile and job outcomes below.

## Job roles

- Cloud Engineer
- Cloud Operations Engineer
- Junior Solutions Architect

## Expected salary ranges

Mid-level cloud roles — treat as directional guidance only.

## Prerequisites

- Comfort with a laptop and a terminal
- Complete earlier phases before later ones when marked ready
- Prefer the [Getting Started](../../getting-started/index.md) overview if you are new to the academy
