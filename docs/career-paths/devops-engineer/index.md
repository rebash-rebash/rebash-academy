# DevOps Engineer

Full-stack platform skills from Linux through CI/CD, containers, Kubernetes, and IaC.

| | |
|--|--|
| **Duration** | 20–28 weeks |
| **Difficulty** | intermediate |
| **Badge** | Recommended |

## Target audience

Engineers who want the **DevOps Engineer** skill profile and job outcomes below.

## Job roles

- DevOps Engineer
- CI/CD Engineer
- Release Engineer

## Expected salary ranges

Mid to senior DevOps roles — treat as directional guidance only.

## Prerequisites

- Comfort with a laptop and a terminal
- Complete earlier phases before later ones when marked ready
- Prefer the [Getting Started](../../getting-started/index.md) overview if you are new to the academy
