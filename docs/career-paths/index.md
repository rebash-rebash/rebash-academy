# Career Paths

A career path is an ordered roadmap towards a specific job role. Paths share the same
tutorials and labs — you follow them in the order that matches your goal, without
duplicated content.

Pick the role you want, check the duration and level, and start with the first
technology in the path.

## How to choose

- **New to IT or Linux?** Start with the [Beginner](beginner/index.md) path — it builds
  the foundations every other path assumes.
- **Already comfortable with Linux?** Go straight to
  [Cloud Engineer](cloud-engineer/index.md) or [DevOps Engineer](devops-engineer/index.md).
- **Working in ops today?** [Platform Engineer](platform-engineer/index.md),
  [Site Reliability Engineer](site-reliability-engineer/index.md), and
  [DevSecOps Engineer](devsecops-engineer/index.md) deepen a specific specialism.
- **Designing systems?** [Cloud Architect](cloud-architect/index.md) covers multi-cloud
  design and Infrastructure as Code (IaC) at scale.

## How paths work

1. Each path lists its technologies in learning order.
2. Every technology links to the shared tutorial track with modules and labs.
3. Finish with the path's projects and interview themes to become job-ready.
