# Capstones

A capstone is the final build of a career path: an end-to-end system that combines
several technologies the way a real platform team would. Each capstone is
portfolio-ready — you can publish the result on GitHub and talk through it in
an interview.

## Planned capstones

| Capstone | Path | Technologies |
|----------|------|--------------|
| Kubernetes platform bootstrap | Kubernetes Engineer | Kubernetes, Helm, ingress, storage |
| GitOps delivery platform | Platform Engineer | Argo CD, GitLab CI, Kubernetes |
| Production monitoring stack | Site Reliability Engineer | Prometheus, Grafana, Loki |
| Cloud landing zone | Cloud Architect | AWS, Terraform, multi-account design |
| Internal developer platform | Platform Engineer | Kubernetes, Terraform, developer experience |
| DevSecOps pipeline | DevSecOps Engineer | GitLab CI, scanning, deploy gates |

Until these ship, the larger entries in [Projects](../projects/index.md) — such as the
Production DevOps Automation Platform — serve as capstone-level builds.
