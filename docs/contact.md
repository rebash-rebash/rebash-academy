# Contact

REBASH Academy is an open learning platform. The fastest way to reach us depends on what you need.

## Feedback and corrections

Spotted a mistake in a tutorial, or want to suggest an improvement? Open an issue on the GitHub repository linked in the site footer. Include the page URL and a short description — small reports are welcome.

## Collaboration

Interested in contributing tutorials, labs, or projects? Read the [About](about/index.md) page for the academy's goals and writing approach, then open a discussion or pull request on GitHub.
