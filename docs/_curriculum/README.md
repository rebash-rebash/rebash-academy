# Curriculum artifacts

Internal design and backlog files for REBASH Academy.

**Source of truth:** [`curriculum.yaml`](../../curriculum.yaml) at the repository root.

These pages are excluded from the public MkDocs site (`exclude_docs`). Use them when planning tutorials, labs, projects, and certification coverage.

| File | Purpose |
|------|---------|
| `quiz-frontmatter-schema.md` | Required frontmatter and body template for every quiz |
| `lab-frontmatter-schema.md` | Required frontmatter and body template for every lab |
| `project-frontmatter-schema.md` | Required frontmatter and body template for every project |
| `capstone-frontmatter-schema.md` | Required frontmatter and body template for every capstone |
| `cheatsheet-frontmatter-schema.md` | Required frontmatter and body template for every cheat sheet |
| `interview-frontmatter-schema.md` | Required frontmatter and question framework for interview prep |
| `certification-frontmatter-schema.md` | Required frontmatter and objective mapping for certification pages |
| `blog-frontmatter-schema.md` | Required frontmatter and article template for the engineering journal |
| `tutorial-frontmatter-schema.md` | Required frontmatter for every tutorial |
| `technology-frontmatter-schema.md` | Required frontmatter for every technology index |
| `technologies_backlog.md` | Technology delivery backlog |
| `tutorial_backlog.md` | Master tutorial implementation order |
| `labs_backlog.md` | Lab backlog |
| `quizzes_backlog.md` | Quiz backlog |
| `projects_backlog.md` | Project and capstone backlog |
| `capstones_backlog.md` | Capstone-only backlog and career-path mapping |
| `cheatsheets_backlog.md` | Cheat sheet backlog and certification mapping |
| `interview_backlog.md` | Interview guides, mock interviews, and system design backlog |
| `certifications_backlog.md` | Certification mapping backlog and progress framework |
| `blog_backlog.md` | Engineering journal article backlog and series roadmap |
| `certification_mapping.md` | Tutorial ↔ certification coverage |

Do not put published tutorials here — they live under `docs/<technology>/`.
