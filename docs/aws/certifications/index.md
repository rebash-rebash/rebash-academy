# AWS — Certification Mapping

This course is **job-first**: production labs and interview stories. Certifications are a useful forcing function — use the mapping below, then practise official exam-style questions separately.

| Certification | Primary modules | Extra focus |
|---------------|-----------------|-------------|
| **Cloud Practitioner** | 1, 2, 13, Well-Architected themes in 14 | Billing, shared responsibility, global infrastructure |
| **Solutions Architect – Associate** | 3–8, 10, 14 | Multi-tier design, HA, storage/DB choice |
| **SysOps Administrator – Associate** | 4, 9, 11–13, 16 | Monitoring, deployments, cost, troubleshooting |
| **DevOps Engineer – Professional** themes | 7, 8, 11, 12, 15 | CI/CD, IaC, multi-account |
| **Security – Specialty** themes | 2, 10, 15 | KMS, IAM, detection, SCPs |

## Suggested study path

1. Complete Modules 1–8 with labs and interview answers aloud  
2. Sit Cloud Practitioner or jump to SAA practice if you already know Linux/networking  
3. Complete Modules 9–16; redraw architectures from memory  
4. Run standalone [IAM/VPC triage](../../labs/aws-iam-vpc-triage.md) under timed conditions  

Official exam guides and sample questions live on [AWS Training and Certification](https://aws.amazon.com/certification/).
