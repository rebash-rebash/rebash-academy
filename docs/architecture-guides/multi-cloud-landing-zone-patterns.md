# Multi-Cloud Landing Zone Patterns

A landing zone is the shared foundation that every workload inherits — identity, networking, logging, and guardrails.

## What you will learn

- Shared services versus application accounts
- Identity federation and least privilege
- Network hubs, spokes, and private connectivity
- Baseline logging and policy as code

## Production scenarios

- Greenfield AWS Organisations or Azure Management Groups
- Connecting on-premises networks without hairpinning traffic
- Separating production and non-production blast radii
