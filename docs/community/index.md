# Community

REBASH Academy is open source. There are no accounts and no logins — everything happens
in the open.

## Contribute

- **Report an issue or request content** — open an issue on the GitHub repository
  linked in the site footer.
- **Improve a tutorial or lab** — fork the repository, edit the Markdown, and open a
  pull request.
- **Share the academy** — tutorials are free to use and link.

## Follow

- **LinkedIn** — engineering posts and release updates.
- **YouTube** — video walkthroughs (coming soon).

All social links are in the site footer on every page.
